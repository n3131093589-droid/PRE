Update Layer Idea

关系感知双向残差更新 示意图

这张图画的是在当前 update layer 基础上继续扩展的一种更强版本：不再只是把 relation-aware residual 加到融合表示上，而是先让 intra 分支和 inter 分支在关系条件下互相改写，再把它们融合成最终的 block 输出。

流程图

读图说明

它比当前 um1 多了什么 当前 um1 主要是对融合后的表示加一个 relation-aware residual。这个想法更进一步，先分别更新 intra 和 inter 两路表示，再融合。
为什么叫双向 因为不是单向把 inter 写回 intra，或者只把 intra 写回 inter，而是两边都在关系条件下互相改写。
这里的关系 r 是什么 还是当前样本里的 type 标签。DrugBank 里是 DDI 类型，Twosides 里是 event / side-effect 类型。
为什么不是门控 这里仍然是 residual update，不是 sigmoid gate。它做的是“补一段关系条件修正”，不是“给已有表示乘系数”。
最小实验写法 可以把当前 update_mode=1 视为 um1，把这个新想法记为 um2。这样对照就会很清晰：um0 -> um1 -> um2。
